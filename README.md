# Prachi Patoliya — AWDF Portfolio

A college-level React portfolio for Advanced Web Development Frameworks practicals 1–7.

## Stack
- React + Vite
- React Router
- GitHub REST API
- Node.js + Express
- MongoDB + Mongoose
- JWT + bcryptjs

## Run frontend
```bash
npm install
npm run dev
```

## Run backend
```bash
cd task-manager-api
npm install
```
Create `.env` from `.env.example` and add a MongoDB Atlas connection string and JWT secret.

```bash
npm run dev
```

Frontend: http://localhost:5173
Backend: http://localhost:5000

## Practical mapping
- Practical 1: reusable React components and props
- Practical 2: React Router and useState
- Practical 3: GitHub API, loading, error and search
- Practical 4: Express REST API and middleware concepts
- Practical 5: MongoDB/Mongoose schema and CRUD
- Practical 6: React + Express + MongoDB task flow
- Practical 7: bcrypt, JWT, authentication middleware and validation
